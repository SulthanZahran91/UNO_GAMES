## 🎨 Animation Architecture

```
Game Action → gameLog Update → Firestore Listener → useEffect Trigger
             ↓
CardAnimation Component → CSS Keyframes → Visual Effect
```

**Flow**:
1. Player plays card → `playCard()` function
2. Backend updates `gameLog` array
3. Frontend `useEffect` detects `gameLog` change (GameRoomActive.jsx:59)
4. Sets `activeAnimation` state with card data
5. `CardAnimation` component renders with keyframe animations
6. On complete, clears animation state

## 📊 Player Count → Layout Mapping

| Players | Opponents | Layout |
|---------|-----------|--------|
| 2 | 1 | Single opponent at top (0°) |
| 3 | 2 | Top-left (-45°), Top-right (+45°) |
| 4 | 3 | Left (-90°), Top (0°), Right (+90°) |
| 5-12 | 4-11 | Circular arc from -90° to +90° |

**Formula**: `angle = -90 + (180 / (total + 1)) * (index + 1)`
